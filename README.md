1. Objetivo e problema

O projeto tem como objetivo desenvolver um modelo de Machine Learning capaz de prever o sucesso financeiro de filmes.

O problema abordado é a dificuldade de estimar se uma produção cinematográfica terá retorno financeiro suficiente para justificar seu investimento.

Serão analisadas características como orçamento, gênero, duração e histórico de produção.

2. Solução proposta

Desenvolver um sistema que utilize dados históricos de filmes para estimar a probabilidade de sucesso comercial de novas produções.

Inicialmente, será considerado um sucesso quando a bilheteria mundial atingir pelo menos duas vezes o orçamento de produção.
